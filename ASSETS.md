# Permission illustrations

Each slot is for a silent, 6-second, looping 800 × 600 MP4 with a dark background. Use the displayed app name **TwinDesk Fork**. Keep the pane title and the control readable throughout. Show these only as optional help, with the same instructions available as text and playback under the user’s control.

| Filename | Settings action to illustrate |
| --- | --- |
| `mac-screen-recording.mp4` | In Privacy & Security › Screen Recording (Screen & System Audio Recording on newer macOS), turn on TwinDesk Fork. |
| `mac-accessibility.mp4` | In Privacy & Security › Accessibility, turn on TwinDesk Fork. |
| `mac-input-monitoring.mp4` | In Privacy & Security › Input Monitoring, turn on TwinDesk Fork when access is missing. |
| `mac-local-network.mp4` | In Privacy & Security › Local Network, turn on TwinDesk Fork. |
| `android-notifications.mp4` | In TwinDesk Fork’s notification settings, turn on notifications. |
| `android-microphone.mp4` | In TwinDesk Fork › Permissions › Microphone, allow access while using the app. |
| `android-nearby-devices.mp4` | In TwinDesk Fork › Permissions › Nearby devices, allow access. |

Grok Imagine returned still images. Video generation was unavailable under the active Zero Data Retention setting, so these slots are pending.
